КАК ДОБАВИТЬ КОРАБЛИ И ЧЕРТЕЖИ НА РЫНОК
=======================================

Путь к базе вводить не нужно. Команды писать не нужно.
Нужен установленный Python 3.11 или новее.

1. ОСТАНОВИ СЕРВЕР РЫНКА — Market.
   Если он работает в отдельном консольном окне, нажми Ctrl+C в том окне.

2. Открой папку своего сервера EveJS.
   Это папка, в которой есть папки mods и externalservices.

3. Открой mods, а в ней — empire-specialized-haulers.
   Файлы Market-Normal.cmd и Market-Hardcore.cmd должны лежать здесь,
   рядом с evejs-launcher.mod.json и fleet.json.

4. ЗАПУСТИ ДВОЙНЫМ ЩЕЛЧКОМ ОДИН ИЗ ДВУХ ФАЙЛОВ:

   Market-Normal.cmd
   Добавляет готовые корабли И чертежи.
   Добавляет SELL и BUY, если у соответствующего оригинала есть оба ордера.
   Если базовые корабли продаются только в Джите — добавит только в Джиту.
   Если они продаются в нескольких хабах — добавит в эти хабы.
   Если продажи распределены по галактике — повторит точки продажи
   соответствующих базовых грузовых кораблей.

   ИЛИ

   Market-Hardcore.cmd
   Добавляет ТОЛЬКО чертежи.
   Только на NPC-станциях своей фракции, где уже продаются чертежи
   соответствующих базовых грузовых кораблей.
   Готовые новые корабли придётся произвести или купить у игроков.

   Не запускай оба файла подряд: второй изменит настройку первого.

5. Откроется окно. Скрипт покажет путь к базе и результат.
   Успешное завершение выглядит так:

   APPLIED normal: ...
   или APPLIED hardcore: ...
   ...
   Finished successfully. Start the Market service again.

   Нажми любую клавишу, чтобы закрыть окно.

6. СНОВА ЗАПУСТИ СЕРВЕР РЫНКА — Market.
   Открой рынок в игре и найди корабль или его Blueprint по названию.

ГОТОВО.


ЕСЛИ ЧТО-ТО НЕ ПОЛУЧИЛОСЬ
-------------------------

Python 3.11 or newer was not found
  Установи Python 3.11 или новее с python.org.
  При установке включи Add python.exe to PATH, если этот пункт показан.
  После установки снова запусти нужный .cmd-файл.

Market database not found
  Сначала создай базу рынка обычным способом для своего сервера.
  Скрипт добавляет товары в готовую базу, а не создаёт весь рынок заново.

Put this mod folder in <EveJS>/mods/empire-specialized-haulers
  Скрипт лежит не на своём месте.
  Помести файлы в папку установленного мода из шага 3.
  Одного .cmd-файла на рабочем столе недостаточно; можно создать ярлык.

database is locked
  Останови сервер Market и снова запусти нужный .cmd-файл.

NOTE: ... no matching ... sellers
  В твоей базе нет подходящих исходных продавцов для указанного корабля.
  Скрипт не придумывает отсутствующие точки продажи.

Cannot seed market / Setup failed
  Прочитай ошибку над этой строкой. Если причина неясна — скопируй
  сообщение целиком. Окно остаётся открытым, пока ты не нажмёшь клавишу.


ПОЛЕЗНО ЗНАТЬ
-------------

Цены берутся у Miasmos, Kryos и Epithal по соответствующей специализации.
Повторный запуск не пополняет уже купленные остатки и не создаёт дубликаты.
При смене режима меняются только NPC-предложения этого мода.
Ордера игроков и остальные товары сохраняются.
После полной перегенерации базы рынка запусти нужный .cmd-файл снова.

Если ты уже запускал скрипт из 0.4.3: обновись до 0.4.4 и запусти
Market-Normal.cmd ещё раз. Он добавит недостающие BUY. Цены и остатки
существующих SELL сохранятся. Для чертежей BUY добавляются только
там, где они есть у исходных чертежей.

Скрипт берёт путь из externalservices/market-server/config/market-server.local.toml
этой установки EveJS. Если настройки нет, использует стандартный файл
externalservices/market-server/data/generated/market.sqlite.
Базы других установок EveJS он не перебирает.
